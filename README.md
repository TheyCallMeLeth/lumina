# Lumina

Plataforma escolar desenvolvida para centralizar a comunicação, organização e colaboração entre estudantes, professores e coordenação em um ambiente moderno, intuitivo e seguro.

## ✨ Funcionalidades

* Sistema de autenticação e autorização
* Cadastro e login de usuários
* Controle de permissões por função (Roles)
* Dashboard personalizado
* Interface responsiva e moderna
* Integração com banco de dados PostgreSQL

## 🛠️ Tecnologias Utilizadas

### Backend

* Java 21
* Spring Boot
* Spring Web
* Spring Security
* Spring Data JPA
* Hibernate

### Banco de Dados

* PostgreSQL

### Frontend

* HTML5
* Thymeleaf
* Tailwind CSS
* JavaScript

### Ferramentas

* Maven
* Lombok
* Spring Boot DevTools

## 🚀 Como Executar

### Pré-requisitos

* Java 21
* Maven
* PostgreSQL

### Executando

```bash
git clone https://github.com/seu-usuario/lumina.git

cd lumina

mvn spring-boot:run
```

A aplicação estará disponível em:

```text
http://localhost:8080
```
